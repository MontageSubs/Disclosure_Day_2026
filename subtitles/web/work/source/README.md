# 原始底本 / Source

本目录存放该版次的官方原始字幕（如 WEB / BluRay 内嵌字幕提取版），由自动化流程下载写入，为只读区域，请勿手动编辑或删除。

## 文件命名

`<lang>.srt`，`<lang>` 为 BCP47 语言标签（如 `en`、`en-US`、`fa`），一种语言对应一个文件。

## 我需要翻译，该去哪里？

原始底本不是翻译工作区。请前往 [`../authored/`](../authored/) 建立你的语言分支后再开始翻译，具体流程见 [贡献指南](../../../../docs/project/CONTRIBUTING.md)。
