# 人工维护区 / Authored

本目录是唯一持续编辑的工作区，翻译、校对、时间轴、特效制作均在此完成。

## main.ass

视觉特效母版，不区分语言，由制作 / 后期在此持续迭代直至最终交付版本。

## `<lang>/main.srt`

若某语言需要独立于 `main.ass` 单独维护（而非依赖自动提取），在此建立对应语言目录并创建 `main.srt`。一旦创建即视为该语言已被人工接管，需持续维护，不再由自动化派生覆盖。

语言目录使用 BCP47 标签命名，如 `zh-Hans/main.srt`、`zh-Hant/main.srt`。
